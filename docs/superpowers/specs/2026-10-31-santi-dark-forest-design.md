# 三体·黑暗森林打击 — 影片设计

日期:2026-10-31 · 目录:`films/2026-10-santi-dark-forest/` · npm 脚本:`santi`

## 目标

用代码渲染一段约 3 分钟的影片,还原《三体》里两次黑暗森林打击:水滴在末日之战中摧毁人类舰队,以及歌者用二向箔把太阳系降为二维。成片要有电影感,不走报告体。

## 视觉系统

画面全部是 2D canvas,每个值都是 `t` 的纯函数(见 Project.md 第 2 节的帧约定)。

- **色彩**:深空近黑偏冷蓝做底。人类舰队用暖金。水滴是纯镜面的白和青。降维之后的"画"用虹彩色和游丝细线(guilloché)。逃离的飞船是一个暖色亮点。
- **星场**:用固定种子生成的点,随 `t` 缓慢视差漂移。
- **舰队**:一个密集的菱形方阵,在 2D 透视投影里排开,看起来有两千艘的量感(不画两千个精灵图)。
- **水滴**:泪滴形,高光随 `t` 移动。它的轨迹是一条在方阵里穿行的光锥。光锥扫过的时刻就是每艘船的熄灭时刻,灯光按闭式弹簧响应衰减,所以熄灭的波纹也是纯函数。
- **歌者**:不画生物。用一大片暗场和冷色的感知点代表它。二向箔是一片翻转着飞向远处太阳的白色小平行四边形。
- **降维**:一张二维前沿平面向内扫。被扫过的天体 z→0,压成布满细纹的虹彩圆盘。由外向内依次发生:海王星、天王星、土星、木星、太阳,最后是地球。
- **逃离与回望**:飞船拖着光速尾迹,冲出正在外扩的扁平地平线。最后拉远,太阳系像一幅装裱好的画挂在黑暗里。
- **文字**:片名、台词字卡、字幕都用中文衬线体:系统自带的 Songti SC,canvas 直接调用,渲染不联网(Look Up 也是这样用 PingFang SC 的)。屏幕文字不小于 26 px。

## 音频

- **旁白**:给 `scripts/voice.py` 加一个分支。narration.json 里写 `"engine": "cosyvoice"` 时,通过 DashScope SDK 调用(国际区 websocket,48 kHz 单声道 WAV)。缓存、裁静音、`phrases()` 和 voice.json 的格式都不变。这一步用 `uv run --with dashscope python3 scripts/voice.py …` 跑。OpenAI 分支保持原样。
- **音乐**:曲子不进 git(Pixabay 授权不允许单独分发文件),放在 `out/santi-music/interstellar-space-travel.mp3`。文件不在时,music.py 报错并打印来源链接。music.py 把它解码成 48 kHz 立体声 WAV,再交给 `narrated.mix()`:旁白时压低音乐,母带处理到 -14 LUFS / -1.5 dBTP。曲子不剪不改,时长就是片长。
- **不用**:MIDI 作曲,也不加转场音效("叮"一类)。

## 管线与文件

```
films/2026-10-santi-dark-forest/
  narration.json   中文旁白,engine=cosyvoice
  voice.json       voice.py 生成
  plan.py          锚点 + 起音检测 → timeline.json(段落时间、台词起点、字幕、熄灭/压平的时刻)
  timeline.json    plan.py 生成
  film.src.html    seek(t) 影片,通过 __TEXT:timeline.json__ 读时间表
  music.py         解码曲子 → narrated.mix()
```

`package.json` 加 `santi`(voice → plan → render → music → mux)、`santi:sheet` 和 `santi:check`,写法照抄 `vas`。

## 验收

1. `npm run santi:check` 通过:没有任何一帧依赖前一帧。
2. 接触表(`--sheet --step 2`)每一段都看得懂,文字不出画。
3. 用 30 fps 预览(`--fps 30 --sub 1`)交给一个独立的美术指导 subagent 打分,9/10 以上才做 `--sub 8` 的终版渲染。
4. 母带在 -14 LUFS ±0.5 以内,峰值不超过 -1.5 dBTP;`mix()` 报告的旁白清晰度为正值。
5. 声音由你来听(我听不到),包括音色和音乐跟画面的配合。

## 风险

- `Planner` 的估算模式按空格数英文单词,中文会估错。所以必须先生成 voice.json,plan.py 要求它存在,不走估算。
- 曲子的锚点来自 1 秒粒度的响度图,可能偏几百毫秒。plan.py 会在锚点 ±0.5 s 内找最强的起音,把时间吸附上去。
- YouTube 上可能有 Content ID 声明,可以凭 Pixabay 授权申诉。

## 不做

不做 3D 和 three.js,不做英文版,不做 deck,不剪辑曲子,不做竖屏版。

## 成片与设计的差异(2026-11-01,美术指导 5 轮,6 → 7 → 8 → 8.5 → 9/10 通过)

- **水滴屠杀**:每次重音是一条连续、不规则的折线航迹,每艘船在航迹的冲击波第一次到达它时爆炸(影响半径有限)。所以死亡区像火一样蔓延,没有整齐的"车道",水滴始终在最前面。0:25–0:29 插入水滴特写(镜面里倒映着舰队)。第二次打击改从舰队内部的低机位拍。旗舰在前景,第四记重音时炸开,碎成三片漂散。所有残骸都碎成三块,断口发光后冷却。
- **歌者**:用一只由冷光点组成的"眼"(三层反向旋转的环)表示。亮弧转向太阳,"瞥了一眼"那一刻有一道视线连到太阳。二向箔在"二向箔"一词时出现在亮弧上,等待期间插一个特写,它侧转成一根发丝时消失。1:14 重音上弹出。1:03 起镜头推向太阳,降维场景从同一机位接上。
- **降维**:不是向内收缩的环,而是从二向箔落点长出的二维圆盘。各天体按"到落点的距离"放在各自轨道上,所以边缘依次按节拍到达:海王星、天王星、土星、木星、太阳(1:57)、地球(2:03,在太阳另一侧)。1:26–1:33 插入海王星侧视英雄镜头:二维平面侧看是一条亮线,行星沉入其中,穿过去的部分化作细碎的虹彩笔触沿线铺开,然后镜头上摇,打开成纹章。太阳压扁后是全片最亮的金白圆盘;地球是蓝白色,大陆展开在环里。
- **逃离**:镜头贴着青白色的针形飞船,二维边缘追上来。光速一跃时星光拉线 1 秒,之后镜头被甩在后面,飞船变成一个远去的光点。2:33 切到回望(比原定早约 4 秒)。片尾字卡放在升起的画下方。
- **音频**:旁白压低音乐 12 dB(`duck=0.25`),旁白比音乐高 6.2 dB。music.py 补回 `mix()` 限幅器吃掉的 0.6 dB,最终 -14.0 LUFS / -2.4 dBTP。
- **画质**:星空底和暗角改为逐像素计算加抖动,暗部渐变不会出现色阶。另外加 3% 的加性颗粒。成片仍是 8-bit H.264,保证手机能播。
- **字幕**:短于 1 秒的片段只在逗号处合并,不跨句。

## v2 重做(2026-11-01,按用户四点意见)

用户意见:① 水滴、舰船和舰队太粗糙;② 太阳系和银河系太粗糙,参考 galaxy-explorer;③ 二向箔要彩虹流光,颜色随角度变化;④ 二向箔进入方向和落点要合原著,冥王星最后二维化,上面留着人类文明的石碑。另加一段:舰队飞离地球。

- **3D 层**:three.js(取自隔壁 galaxy-explorer 的 vendor,MIT)渲染到一张 WebGL 画布,再画进 2D 画布,字幕、字卡、颗粒仍在 2D。每个场景一个文件,`draw(t)` 仍是 `t` 的纯函数:`gl-core.js`(渲染器、辉光、工具)、`gl-galaxy.js`(银河系 + 冷开场)、`gl-ships.js`(战舰模型、点精灵)、`gl-earth.js`(飞离地球)、`gl-fleet.js`(末日之战)、`gl-singer.js`(二向箔材质 + 歌者)、`gl-solar.js`(太阳系降维)、`gl-pluto.js`(冥王星石碑与逃离)。上面的"不做 3D 和 three.js"作废。
- **银河系**:照 galaxy-explorer 的做法:油画质感的银盘(着色器,`bake-galaxy.mjs` 离线烘焙一次到 `out/santi-galaxy/milkyway.jpg`,因为成片用软件 GL)、三万颗按旋臂成团的星、核心辉光,太阳在半径一半处的小旋臂上。冷开场从太阳附近的星群里拉起,露出整个银河,四只"眼睛"在星上睁开。其余场景的天空是这个银河从太阳处看出去的样子(启动时渲染进立方体贴图),所以战场、地球、冥王星上空的银河带是同一个银河。
- **飞离地球**(0:11–0:18):白天一侧和夜面城市灯光的地球,140 艘战舰在片名的重音上依次点火,从镜头旁掠过;"它们列成方阵"切到方阵。
- **舰队与水滴**:实体建模的恒星级战舰(实例化),水滴是纯镜面泪滴,特写里倒映着舰队。
- **歌者**:从银河的上方俯视;那只眼仍是 2D 冷光点环,亮弧转向银河里的太阳。二向箔是薄膜干涉着色器:厚度条纹随时间流动,条纹颜色随视角平移,侧到正侧面只剩一根发丝。弹出后缩成一个变色的光点,镜头跟着它俯冲进太阳附近的星群,切到太阳系。
- **降维**:二向箔从冥王星对侧滑入,落在海王星轨道外侧;二维区从落点长出,按原著顺序吞没海王星 → … → 太阳 → 地球,冥王星最后。行星带纹理,压扁时整张表面展开成环,内部分层在环内。
- **冥王星**:逃离从冥王星上开始,冰原上立着刻有多种人类文字(楔形文字、圣书体、中文、希腊文、拉丁文、阿拉伯文、希伯来文、天城文、俄文、日文、英文)的石碑;冥王星最后被压平时,碑文留在它的画里。
- **新增旁白**:"最后是冥王星,和刻在它石碑上的人类文明。"
