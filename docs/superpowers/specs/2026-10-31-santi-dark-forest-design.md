# 三体·黑暗森林打击 — 影片设计

日期:2026-10-31 · 目录:`films/2026-10-santi-dark-forest/` · npm 脚本:`santi`

## 目标

用代码渲染一段约 3 分钟的影片,还原《三体》里两次黑暗森林打击:水滴在末日之战中摧毁人类舰队,以及歌者用二向箔把太阳系降为二维。成片要有电影感,不走报告体。

## 已定决策

| 项 | 决定 |

## 视觉系统

画面全部是 2D canvas,每个值都是 `t` 的纯函数(见 Project.md 第 2 节的帧约定)。

- **色彩**:深空近黑偏冷蓝做底。人类舰队用暖金。水滴是纯镜面的白和青。降维之后的"画"用虹彩色和游丝细线(guilloché)。逃离的飞船是一个暖色亮点。
- **星场**:用固定种子生成的点,随 `t` 缓慢视差漂移。
- **舰队**:一个密集的菱形方阵,在 2D 透视投影里排开,看起来有两千艘的量感(不画两千个精灵图)。
- **水滴**:泪滴形,高光随 `t` 移动。它的轨迹是一条在方阵里穿行的光锥。光锥扫过的时刻就是每艘船的熄灭时刻,灯光按闭式弹簧响应衰减,所以熄灭的波纹也是纯函数。
- **歌者**:不画生物。用一大片暗场和冷色的感知点代表它。二向箔是一片翻转着飞向远处太阳的白色小平行四边形。
- **降维**:一张二维前沿平面向内扫。被扫过的天体 z→0,压成布满细纹的虹彩圆盘。由外向内依次发生:海王星、天王星、土星、木星、太阳,最后是地球。
- **逃离与回望**:飞船拖着光速尾迹,冲出正在外扩的扁平地平线。最后拉远,太阳系像一幅装裱好的画挂在黑暗里。
- **文字**:片名、台词字卡、字幕都用中文衬线体:系统自带的 Songti SC,canvas 直接调用,渲染不联网(Look Up 也是这样用 PingFang SC 的)。屏幕文字不小于 26 px。

## 音频

- **旁白**:给 `scripts/voice.py` 加一个分支。narration.json 里写 `"engine": "cosyvoice"` 时,通过 DashScope SDK 调用(国际区 websocket,48 kHz 单声道 WAV)。缓存、裁静音、`phrases()` 和 voice.json 的格式都不变。这一步用 `uv run --with dashscope python3 scripts/voice.py …` 跑。OpenAI 分支保持原样。
- **音乐**:曲子不进 git(Pixabay 授权不允许单独分发文件),放在 `out/santi-music/interstellar-space-travel.mp3`。文件不在时,music.py 报错并打印来源链接。music.py 把它解码成 48 kHz 立体声 WAV,再交给 `narrated.mix()`:旁白时压低音乐,母带处理到 -14 LUFS / -1.5 dBTP。曲子不剪不改,时长就是片长。
- **不用**:MIDI 作曲,也不加转场音效("叮"一类)。

## 管线与文件

```
films/2026-10-santi-dark-forest/
  narration.json   中文旁白,engine=cosyvoice
  voice.json       voice.py 生成
  plan.py          锚点 + 起音检测 → timeline.json(段落时间、台词起点、字幕、熄灭/压平的时刻)
  timeline.json    plan.py 生成
  film.src.html    seek(t) 影片,通过 __TEXT:timeline.json__ 读时间表
  music.py         解码曲子 → narrated.mix()
```

`package.json` 加 `santi`(voice → plan → render → music → mux)、`santi:sheet` 和 `santi:check`,写法照抄 `vas`。

## 验收

1. `npm run santi:check` 通过:没有任何一帧依赖前一帧。
2. 接触表(`--sheet --step 2`)每一段都看得懂,文字不出画。
3. 用 30 fps 预览(`--fps 30 --sub 1`)交给一个独立的美术指导 subagent 打分,9/10 以上才做 `--sub 8` 的终版渲染。
4. 母带在 -14 LUFS ±0.5 以内,峰值不超过 -1.5 dBTP;`mix()` 报告的旁白清晰度为正值。
5. 声音由你来听(我听不到),包括音色和音乐跟画面的配合。

## 风险

- `Planner` 的估算模式按空格数英文单词,中文会估错。所以必须先生成 voice.json,plan.py 要求它存在,不走估算。
- 曲子的锚点来自 1 秒粒度的响度图,可能偏几百毫秒。plan.py 会在锚点 ±0.5 s 内找最强的起音,把时间吸附上去。
- YouTube 上可能有 Content ID 声明,可以凭 Pixabay 授权申诉。

## 不做

不做 3D 和 three.js,不做英文版,不做 deck,不剪辑曲子,不做竖屏版。
